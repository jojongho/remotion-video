# 🎬 모션 프리셋 가이드

> Remotion 자막/오버레이 작업 시 이 노트를 컨텍스트로 제공하면 모션 설명 없이 프리셋 이름만으로 적용 가능.

---

## 📌 사용법

> "자막에 `M-03` 적용해줘"  
> "인트로는 `M-07`, 아웃트로는 `M-02` 반전으로"

---

## 🔵 등장 모션 (IN)

### M-01 | 페이드인
- 투명 → 불투명 (opacity: 0 → 1)
- 속도: 0.5초
- 용도: 일반 자막, 정보 카드

### M-02 | 슬라이드업
- 아래에서 위로 이동하며 등장 (translateY: 50px → 0)
- 속도: 0.4초
- 용도: 기본 자막, 하단 바

### M-03 | 슬라이드 레프트인
- 왼쪽에서 오른쪽으로 슬라이드 (translateX: -100px → 0)
- 속도: 0.4초
- 용도: 정보 카드, 사이드 패널

### M-04 | 슬라이드 라이트인
- 오른쪽에서 왼쪽으로 슬라이드 (translateX: 100px → 0)
- 속도: 0.4초
- 용도: 정보 카드, 보조 텍스트

### M-05 | 팝업 (스프링)
- 작게 → 크게 + 바운스 (scale: 0.5 → 1, spring)
- 속도: 0.6초 (스프링 탄성)
- 용도: 강조 텍스트, 가격, 숫자

### M-06 | 줌인
- 크게 → 정상 크기 (scale: 1.5 → 1) + 페이드인
- 속도: 0.5초
- 용도: 섹션 타이틀, 임팩트 있는 등장

### M-07 | 타이핑
- 글자가 한 자씩 나타남 (width clip or letter reveal)
- 속도: 글자당 0.05초
- 용도: 인트로 타이틀, 중요 문구

### M-08 | 박스 펼침 → 텍스트
- 배경 박스가 먼저 가로로 펼쳐짐 → 텍스트 페이드인
- 속도: 박스 0.3초 → 텍스트 0.3초
- 용도: 자막바, 정보 레이블

### M-09 | 블러 → 선명
- 흐릿한 상태 → 선명 (filter blur: 10px → 0)
- 속도: 0.5초
- 용도: 분위기 있는 등장, 다큐 스타일

### M-10 | 드롭인
- 위에서 아래로 떨어지며 바운스 (translateY: -80px → 0, spring)
- 속도: 0.5초
- 용도: 예능 스타일, 강조

## 🔴 퇴장 모션 (OUT)

### M-11 | 페이드아웃
- 불투명 → 투명 (opacity: 1 → 0)
- 속도: 0.3초

### M-12 | 슬라이드다운
- 현재 위치 → 아래로 사라짐 (translateY: 0 → 50px) + 페이드
- 속도: 0.3초

### M-13 | 슬라이드 레프트아웃
- 현재 위치 → 왼쪽으로 사라짐 (translateX: 0 → -100px)
- 속도: 0.3초

### M-14 | 슬라이드 라이트아웃
- 현재 위치 → 오른쪽으로 사라짐 (translateX: 0 → 100px)
- 속도: 0.3초

### M-15 | 축소 아웃
- 정상 크기 → 작아지며 사라짐 (scale: 1 → 0.5) + 페이드
- 속도: 0.3초

### M-16 | 블러아웃
- 선명 → 흐릿 + 페이드 (blur: 0 → 10px, opacity → 0)
- 속도: 0.4초

---

## 🟡 루프/유지 모션 (LOOP)

### M-20 | 글로우 펄스
- 텍스트 그림자가 밝아졌다 어두워짐 반복
- 주기: 2초
- 용도: 가격, 핵심 수치 강조

### M-21 | 플로팅
- 위아래 미세하게 떠다니는 움직임 (translateY: ±5px)
- 주기: 3초
- 용도: 아이콘, 배지

### M-22 | 쉐이크
- 좌우로 짧게 흔들림
- 주기: 0.5초 (1회성)
- 용도: 강조, 경고, 예능 리액션

### M-23 | 컬러 쉬프트
- 텍스트/배경 색상이 서서히 변화
- 주기: 4초
- 용도: 분위기 연출, 무드

---

## 🟢 자막 전용 모션

### M-30 | 틱톡 스타일
- 자막 페이지 단위 교체 (페이드 전환)
- 현재 단어 하이라이트 (색상 변경)
- 용도: 숏폼, 강조형 자막

### M-31 | 캐러셀 (카드 교체)
- 자막 카드가 슬라이드로 교체 (좌→우 또는 아래→위)
- 용도: 긴 문장, 정보 전달

### M-32 | 워드 바이 워드
- 단어가 하나씩 등장 (M-01 또는 M-05 개별 적용)
- 용도: 임팩트 있는 한 줄 강조

### M-33 | 다큐 자막
- 하단 반투명 바 + 텍스트 페이드인 (M-08 변형)
- 깔끔하고 정돈된 느낌
- 용도: 다큐멘터리, 부동산 정보 전달

### M-34 | 뉴스 자막
- 좌측에서 라인이 먼저 나타남 → 텍스트 슬라이드인
- 용도: 공식 정보, 뉴스 스타일

## 🟣 조합 프리셋 (자주 쓰는 세트)

### P-01 | 기본 자막 세트
- 등장: `M-02` (슬라이드업)
- 유지: 없음
- 퇴장: `M-11` (페이드아웃)

### P-02 | 강조 정보 세트
- 등장: `M-05` (팝업 스프링)
- 유지: `M-20` (글로우 펄스)
- 퇴장: `M-15` (축소 아웃)

### P-03 | 정보 카드 세트
- 등장: `M-03` (슬라이드 레프트인)
- 유지: 없음
- 퇴장: `M-14` (슬라이드 라이트아웃)

### P-04 | 인트로 세트
- 등장: `M-06` (줌인) + `M-09` (블러→선명)
- 유지: `M-20` (글로우 펄스)
- 퇴장: `M-16` (블러아웃)

### P-05 | 다큐/부동산 세트
- 등장: `M-08` (박스 펼침 → 텍스트)
- 유지: 없음
- 퇴장: `M-11` (페이드아웃)

### P-06 | 예능 강조 세트
- 등장: `M-10` (드롭인)
- 유지: `M-22` (쉐이크)
- 퇴장: `M-15` (축소 아웃)

## ⚙️ 속도 조절

| 키워드 | 배수 | 설명 |
|--------|------|------|
| **느리게** | ×1.5 | 기본 속도의 1.5배 시간 |
| **기본** | ×1.0 | 위에 명시된 기본 속도 |
| **빠르게** | ×0.5 | 기본 속도의 절반 시간 |
| **즉시** | 0초 | 애니메이션 없이 즉시 표시 |

> 예: "M-05 느리게" = 팝업 스프링을 0.9초로 적용
