# 🎨 Remotion 스타일 프리셋 가이드

> 레퍼런스: 걸리버하우스 건축 영상 + 유튜브 인트로 스타일
> 코드 파일: `src/styles/presets.ts`

---

## 📋 프리셋 목록

### 기본 텍스트 (걸리버하우스 스타일)

| 코드 | 이름 | 용도 | 핵심 특징 |
|------|------|------|-----------|
| `mainTitle` | 메인 타이틀 | 인트로, 프로젝트명 | 세리프 80px, 흰색, 자간 넓게 |
| `sectionTitle` | 섹션 타이틀 | 공간명 (거실, 주방) | 고딕 48px, 좌측 골드 라인 |
| `subTitle` | 서브 타이틀 | 부가 설명 | 고딕 28px, 회색 |
| `keyNumber` | 핵심 수치 | 가격, 면적 | 고딕 64px, 골드 |
| `minimalCaption` | 미니멀 캡션 | 일반 자막 | 고딕 36px, 흰색, 미세 그림자 |

### 🔥 강조 텍스트 (유튜브 인트로 스타일)

| 코드 | 이름 | 용도 | 핵심 특징 |
|------|------|------|-----------|
| `emphasisWord` | 강조 텍스트 | "꼭" 스타일 1~2글자 | 임팩트체 120px, **노란색**, 강한 그림자 |
| `emphasisSingle` | 초대형 강조 | 한 글자 강조 | 임팩트체 160px, 노란색 |
| `emphasisBody` | 강조 옆 본문 | "가봐야하는 국내여행지" | 고딕 48px, 흰색, 굵게 |
| `archLabel` | 곡선 영문 | "SOUTH KOREA" 스타일 | 고딕 22px, 골드, 대문자, 넓은 자간 |

### 카드/배지 스타일

| 코드 | 이름 | 용도 | 핵심 특징 |
|------|------|------|-----------|
| `infoLabel` | 정보 라벨 | 면적/방수 한 줄 정보 | 반투명 검정 배경 + 블러 |
| `infoCard` | 정보 카드 | 상세 정보 박스 | 다크 글래스 카드, 라운드 |
| `infoCardTitle` | 카드 제목 | 카드 내부 제목 | 고딕 36px, 흰색 |
| `infoCardBody` | 카드 본문 | 카드 내부 설명 | 고딕 22px, 밝은 회색 |
| `tagBadge` | 태그 배지 | #모델하우스 | 골드 테두리, 라운드 |
| `hashtagBadge` | 해시태그 배지 | #국내여행 | **반투명 다크 배경**, 흰색, 라운드 |
| `hashtagRow` | 해시태그 행 | 배지 가로 나열 컨테이너 | flex, gap 16px |
| `locationLabel` | 위치 라벨 | 📍 주소 표시 | 베이지 텍스트 |

### 📣 부동산 광고 스페셜 (전단지/블로그 썸네일)

| 코드 | 이름 | 용도 | 핵심 특징 |
|------|------|------|-----------|
| `adStrokeText` | 메인 헤드라인 | "분양예정", "매물접수" | Gmarket 굵은 고딕, 초대형, **강한 외곽선(Stroke)** |
| `adHighlightBox` | 강조 하이라이트 | "매출 쌉보장!" | Gmarket, 노란 배경 + 네이비 글씨 박스 |
| `adVerticalBanner` | 세로 배너 | 우측 세로 안내문구 | 임팩트체, 세로 나열, 빨강/흰색 강한 대비 |
| `adPhoneBox` | 번호 박스 | 전화번호 표시 | Gmarket, 모서리 둥근 테두리 박스 |
| `adRibbon` | 리본 배너 | "부동산 소식" 타이틀 | Gmarket, 양끝이 잘린 리본 형태 백그라운드 |

### 기타

| 코드 | 이름 | 용도 |
|------|------|------|
| `divider` | 구분선 | 골드 수평선 |
| `cta` | CTA 버튼 | 좋아요/구독 |
| `watermark` | 워터마크 | 채널명, 반투명 |

## 🎨 컬러 팔레트

```
흰색 계열:  #FFFFFF → #F5F5F0 → #E8E8E3
회색 계열:  #B5B0A8 → #8A8580 → #3D3D3D
다크 계열:  #2A2A2A → #1A1A1A
포인트:     #C9A96E (골드) | #4A6741 (포레스트)
강조:       #FFD700 (노랑) | #FF8C00 (주황) | #FF4444 (빨강) | #00D4FF (시안)
광고 원색:  #E61919 (빨강) | #FFE600 (노랑) | #002855 (네이비) | #005BAC (파랑)
```

## 💬 사용 예시

```
"인트로에 emphasisWord로 '꼭' + emphasisBody로 '가봐야하는 국내여행지',
 하단에 hashtagBadge로 #부동산 #모델하우스 #분양"
```

```
"각 공간 소개할 때 sectionTitle + subTitle,
 가격은 keyNumber, 일반 자막은 minimalCaption"
```

```
"정보 카드 infoCard로 우하단에,
 태그는 tagBadge로 상단에 나열"
```

## 📐 위치 프리셋

| 코드 | 위치 |
|------|------|
| `center` | 화면 정중앙 |
| `bottomCenter` | 하단 중앙 (자막) |
| `bottomLeft` | 좌하단 |
| `topLeft` | 좌상단 |
| `topRight` | 우상단 |
| `centerLeft` | 좌측 중앙 |
| `bottomRight` | 우하단 (정보 카드) |
| `rightVertical` | 우측 세로 (전단지 세로 배너용) |
