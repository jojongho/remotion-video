# 🏢 사업개요 템플릿 가이드

> 코드: `src/templates/PropertyInfoImageVersion.tsx` (A)
> 코드: `src/templates/PropertyInfoOverlayVersion.tsx` (B)

---

## Version A: 이미지 + 텍스트

**용도**: 흰 배경에 좌측 투시도 + 우측 정보

| 구성 | 설명 |
|------|------|
| 좌측 | 아파트 투시도/조감도 이미지 |
| 우측 | 정보 항목 리스트 (순차 등장) |
| 상단 | 섹션 라벨("사업개요") + 브랜드 로고 |
| 배경 | 흰색 |
| 애니메이션 | 이미지 ← 슬라이드인, 항목 ↑ 페이드인 (순차) |

### Props

```
imageSrc       (필수) 투시도 이미지 경로
title          (필수) 프로젝트명
items          (필수) [{label, value}] 배열
sectionLabel   (선택) 기본 "사업개요"
brandName      (선택) 우상단 브랜드명
logoSrc        (선택) 우상단 로고 이미지
accentColor    (선택) 강조색, 기본 네이비
```

## Version B: 영상 배경 + 오버레이

**용도**: 영상 위에 올리는 투명 오버레이

| 구성 | 설명 |
|------|------|
| 배경 | 투명 (프리미어에서 영상 위에 올림) |
| 1단계 | 반투명 검정 배경 페이드인 (0~1초) |
| 2단계 | 섹션 라벨 + 타이틀 ↑ 페이드인 (0.8~1.5초) |
| 3단계 | 골드 구분선 ← 확장 (1.2~1.8초) |
| 4단계 | 정보 항목 ← 슬라이드인 (1.5초~ 순차) |

### Props

```
title          (필수) 프로젝트명
items          (필수) [{label, value}] 배열
sectionLabel   (선택) 기본 "사업개요"
overlayOpacity (선택) 배경 불투명도, 기본 0.75
layout         (선택) "center" | "left" | "right"
accentColor    (선택) 구분선/라벨 컬러, 기본 골드
```

## 렌더링 방법

### Version A (흰 배경)
```bash
npx remotion render PropertyInfoA --codec=h264 out/property-info-a.mp4
```

### Version B (투명 배경 → 프리미어에서 합성)
```bash
npx remotion render PropertyInfoB --codec=vp8 out/property-info-b.webm
```
